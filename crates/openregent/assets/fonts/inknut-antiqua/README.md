# Inknut Antiqua

openregent's text font (`src/ui/typeface.rs`, `[ui] font = "inknut"`), built
into the binary. Weight 400, the `latin` and `latin-ext` subsets, from
a download's `static/` folder, named as
[Fontsource](https://fontsource.org/fonts/inknut-antiqua) names its
files (**Inferred**: Fontsource's); not modified.
